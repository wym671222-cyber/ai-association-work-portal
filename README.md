# AI协会工作门户

深圳市安居建业投资运营有限公司 AI协会内部工作门户。

## 重要说明

本仓库包含标注为“内部使用”的工作资料、项目数据和调研汇总，不得未经授权公开发布或对外传播。

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

构建结果位于 `dist/`，并会复制门户资料到 `dist/resources/`。

## GitHub Pages

`docs/` 是准备好的 GitHub Pages 发布目录。启用 Pages 会使站点可能对互联网公开，启用前必须确认资料权限和访问控制要求。
